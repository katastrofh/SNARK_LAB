# SNARK_LAB v0.2.0-rc.1

SNARK_LAB v0.2.0-rc.1 is a release candidate for a Rust protocol lab covering Sumcheck, Zerocheck, PermCheck, IPA polynomial commitments, fuzzing, public vectors, release evidence, and an educational visualizer.

## Status

This is a release candidate for review, reproducibility checks, and protocol study.

It is not production-secure software.

Do not use this release for production funds, custody, consensus-critical systems, or security-critical deployment.

## Highlights

- Rust implementations of core SNARK protocol building blocks
- Sumcheck, Zerocheck, PermCheck, and IPA PCS components
- IPA proof codec hardening
- Fuzz smoke evidence for all fuzz targets
- Fuzz crash regression suite
- Public test vectors
- SRS provenance and placeholder-policy checks
- Deployment evidence templates
- Audit-readiness packet
- Visualizer screenshots and browser visualizer
- GitHub release artifact tooling
