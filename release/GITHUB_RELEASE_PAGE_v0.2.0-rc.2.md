# SNARK_LAB v0.2.0-rc.2

SNARK_LAB v0.2.0-rc.2 is a release candidate from current main for a Rust protocol lab covering Sumcheck, Zerocheck, PermCheck, IPA polynomial commitments, fuzzing, public vectors, release evidence, and an educational visualizer.

## Status

This is a release candidate for review, reproducibility checks, and protocol study.

It is not production-secure software.

Do not use this release for production funds, custody, consensus-critical systems, or security-critical deployment.
