# Visualizer Example

The browser visualizer explains the protocol flow interactively.

## What to inspect

Look for:

- System tab
- IPA tab
- Sumcheck tab
- Zerocheck tab
- PermCheck tab
- Scribe tab

## Run locally

    cd web/visualizer
    npm ci
    npm run dev

Open:

    http://localhost:5173/?tab=system
    http://localhost:5173/?tab=ipa
    http://localhost:5173/?tab=sumcheck
    http://localhost:5173/?tab=zerocheck
    http://localhost:5173/?tab=permcheck
    http://localhost:5173/?tab=scribe
