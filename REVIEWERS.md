# Reviewer Quick Start

SNARK_LAB is a Rust SNARK protocol lab with Sumcheck, Zerocheck, PermCheck, IPA polynomial commitments, fuzzing, public vectors, release evidence, and an educational visualizer.

## Boundary

This repository is for protocol study, implementation review, and reproducibility.

It is not deployment-grade cryptographic infrastructure.
