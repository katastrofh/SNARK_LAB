# Paper-Style Technical Overview Notes

This branch adds paper-like overview material for reviewers and researchers.

## Added

- `docs/paper-style-technical-overview.md`
- `docs/protocol-stack-summary.md`
- `scripts/check-paper-style-technical-overview.sh`

## Purpose

The overview gives readers a compact, paper-style description of the repository.

It explains:

- motivation
- scope
- protocol stack
- IPA commitment path
- evidence model
- release model
- visualizer role
- limitations

## Boundary

The overview presents the project as a protocol lab and research-engineering artifact.

It does not make deployment claims.
