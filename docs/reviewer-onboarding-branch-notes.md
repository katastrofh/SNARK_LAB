# Reviewer Onboarding Branch Notes

This branch adds reviewer-facing entry points.

## Added

- `docs/reviewer-onboarding-guide.md`
- `REVIEWERS.md`
- `scripts/check-reviewer-onboarding-guide.sh`

## Purpose

The goal is to make the repository easier for outside reviewers to inspect.

The guide points reviewers to:

- the main production-readiness evidence gate
- release candidate files
- publication evidence
- protocol components
- fuzzing evidence
- SRS boundary documents
- visualizer assets

## Boundary

The guide keeps the repository positioned as a protocol lab and research prototype.
