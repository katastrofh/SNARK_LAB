# README Star Polish

This document records the GitHub-facing README polish.

## Added

- stronger top-level project pitch
- protocol map
- quickstart
- evidence table
- release-candidate status
- clear non-production boundary
- suggested reading order
- README quality checker

## Goal

The README should let a visitor understand the project in under one minute:

- what the repo is
- why it matters
- what protocols it covers
- how to run checks
- what evidence exists
- what is not yet production-secure

## Boundary

The README must not overclaim security.

The project is a production-grade research prototype and release candidate, not audited production-secure deployment software.
