# Examples Gallery

This document records the examples gallery for SNARK_LAB.

- Sumcheck example

## Purpose

The examples gallery gives reviewers and new readers a fast path through the repository.

It points to the main commands, files, and manual review questions for each protocol or evidence area.

## Boundary

The examples are educational and review-oriented.

They are not instructions for deployment in security-critical settings.
