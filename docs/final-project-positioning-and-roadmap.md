# Final Project Positioning and Roadmap

This document records the final positioning layer for SNARK_LAB.

## Added

- `docs/project-positioning.md`
- `ROADMAP.md`
- `scripts/check-final-project-positioning-and-roadmap.sh`

## Purpose

The repository should be easy to understand within the first minute.

The positioning documents clarify:

- what the project is
- what the project is not
- why the project is useful
- what evidence exists
- what remains before any production-security claim
- what future research and engineering work could follow

## Boundary

The project is positioned as a research prototype and protocol lab.

It must not claim production security, custody safety, mainnet readiness, or external audit completion.
