# Visualizer System Flow

This branch adds a system-level visual map to the browser visualizer.

## Added

The new System tab visualizes the actual repository pipeline:

- statement and witness input
- multilinear algebra layer
- Fiat-Shamir transcript binding
- Sumcheck, Zerocheck, and PermCheck reductions
- IPA polynomial commitment path
- proof codecs and SRS validation
- CLI and public test vectors
- fuzzing, CI, and production gates

## Why this matters

The IPA tab explains one protocol path.

The System tab explains how the whole repository fits together as a production-grade research prototype.

## Boundary

The System tab is an educational map of implemented components.

It is not an audit, not production deployment evidence, and not a production SRS ceremony.
